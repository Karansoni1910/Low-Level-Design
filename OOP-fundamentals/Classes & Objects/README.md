# 🏗️ Classes & Objects

**Definition:** Classes are blueprints that define the structure and behavior of objects, which are instances of those classes containing data (fields) and functionality (methods).

---

## 📋 Problem Statement

Create a **BankAccount** class that manages a simple bank account with deposit, withdrawal, and balance checking functionality.

---

## ✅ Requirements

- **Fields:** `accountNumber`, `ownerName`, `balance`
- **Constructor:** Initializes the account with owner name and account number (balance starts at 0)
- **`deposit(amount)`:** Adds money to balance (only positive amounts)
- **`withdraw(amount)`:** Removes money if sufficient balance exists, returns success/failure
- **`getBalance()`:** Returns current balance

---

## 💡 Key Concepts Covered

- Object creation and initialization
- Encapsulation of data
- Method implementation
- State management
